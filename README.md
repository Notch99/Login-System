# Login System Mod

Welcome to the **Login System Mod** repository! 

Since this mod supports multiple mod loaders (Fabric, NeoForge, and Forge), the source code for each version is kept in its own dedicated branch.

Please select the branch corresponding to your mod loader from the dropdown menu above, or click one of the links below:

- [**Fabric Branch**](https://github.com/Notch99/Login-System/tree/fabric) - For the Fabric version (v2.2+)
- [**NeoForge Branch**](https://github.com/Notch99/Login-System/tree/neoforge) - For the NeoForge version (v2.2+)
- [**Forge Branch**](https://github.com/Notch99/Login-System/tree/forge) - For the Forge version (v2.0+)
