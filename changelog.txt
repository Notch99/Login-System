# 🔐 Login System Mod - Changelog

## v1.3.0 (Latest) - Augest 2025
### 🎉 Major Updates
- ✅ **Embedded JDBC Drivers**: Added MySQL and MariaDB drivers directly in JAR
- ✅ **Advanced Admin Commands**: Complete overhaul of admin command system
- ✅ **UUID Support**: Full support for both online and offline players
- ✅ **Password Management**: Admin can now view plain text passwords
- ✅ **Database Optimization**: Improved connection handling and error recovery

### 🔧 Technical Improvements
- ✅ **JAR Size Optimization**: Reduced to ~3MB while including all drivers
- ✅ **Enhanced Error Handling**: Better error messages and logging
- ✅ **Memory Optimization**: Reduced memory footprint
- ✅ **Thread Safety**: Improved concurrent access handling
- ✅ **Build System**: Updated to Gradle 8.8 with Java 17

### 🆕 New Features
- `/loadmin resetpass <player> <newPassword>` - Reset any player's password
- `/loadmin list` - View all registered players with UUIDs
- Automatic plain text password storage for admin access
- Support for UUID-based player identification
- Enhanced debug logging system

### 🐛 Bug Fixes
- Fixed SQLite URL issues in admin commands
- Resolved lambda variable scope issues
- Fixed database connection timeout problems
- Corrected UUID generation for offline players
- Fixed dependency loading issues

### ⚡ Performance
- Faster database queries with prepared statements
- Optimized password hashing operations  
- Reduced startup time
- Better resource cleanup
