# 🔐 Login System Mod - Changelog

## v1.6.0 (Latest) - January 2026
### 🛡️ Security Enhancement Update

### 🚨 Admin Alert System (NEW!)
- **Suspicious Login Detection**: Alerts admins when a player fails login 3+ times
- **Real-time Notifications**: Admins receive instant alerts with:
  - Player name
  - Player IP address
  - Number of failed attempts
  - Security warning message
- **Console Logging**: Security events logged for review
- **Configurable**: Enable/disable and customize max attempts in config

### ⚙️ New Configuration Options
```properties
# Admin Alert Settings
enableAdminAlerts=true
maxFailedAttempts=3
```

## v1.4.0 - October 2025
### 🎉 Major Updates - GUI Revolution
- 🎨 **NEW: Complete Admin GUI System**: Revolutionary graphical interface for player management
- 🖱️ **Interactive Player Management**: Click-based account management with real-time updates
- 👤 **Real Minecraft Skins**: Player heads display actual player skins automatically
- 🔒 **Ultimate Security**: 13+ comprehensive protection systems for unlogged players
- 💬 **Instant Password Access**: Hover tooltips and click-to-view password system
- 🔄 **Auto-Tracking**: Automatic plain-text password storage for admin convenience

### 🎨 New GUI Features
- **Main Menu Interface**: Clean 3-row GUI with centered icons
  - 📖 **Info Book**: Browse all players with passwords (hover to view)
  - 🚫 **Barrier**: One-click player deletion system
- **Player List View**: 6-row display with player heads showing real skins
- **Tooltip System**: Hover over any player to see password instantly
- **Click Actions**: Click player head to display password in chat
- **Auto-Refresh**: GUI updates automatically after deletions
- **Offline Support**: Works with both online and offline player skins

### 🛡️ Enhanced Security Systems (13 Protection Layers)
Complete lockdown for unlogged players:
1. ✅ Movement restriction (waiting area confinement)
2. ✅ Block breaking prevention
3. ✅ Block placing prevention
4. ✅ Item interaction blocking
5. ✅ Entity attack prevention
6. ✅ Damage dealing prevention
7. ✅ Item dropping restriction
8. ✅ Item pickup blocking
9. ✅ Chat message prevention
10. ✅ Container/chest access blocking
11. ✅ All interaction types disabled
12. ✅ Damage immunity (no death while unlogged)
13. ✅ Inventory hiding system

### 🔧 Command Simplification
- **Removed**: `/loadmin info <player>` and `/loadmin delete <player>`
- **New**: Single `/loadmin` command opens GUI for all operations
- Cleaner, more intuitive admin experience

### 🆕 Technical Features
- Custom `AdminGUIMenu` class for GUI handling
- Dynamic container sizing (27 or 54 slots)
- NBT tag system for GUI actions
- Real-time password tracking on `/changepassword`
- Player skin rendering via `SkullOwner` NBT

### 🐛 Bug Fixes
- Fixed `EntityItemPickupEvent` import path
- Resolved null pointer in `LivingAttackEvent`
- Corrected GUI slot calculations
- Fixed menu type selection for different container sizes

### ⚡ Performance
- Optimized GUI rendering
- Efficient NBT tag handling
- Minimal memory overhead for GUI system
- Fast player skin loading
